# แผนที่คอนโดสูงที่มีข้อสังเกตเรื่องพื้นที่รอบอาคาร (condo-safety-map)

เว็บแอปแผนที่แสดงตำแหน่งคอนโดมิเนียม 50 แห่งที่สภาผู้บริโภคระบุว่ามีข้อสังเกตเรื่อง
การจัดพื้นที่รอบอาคาร ตามข้อกำหนดของ "อาคารขนาดใหญ่พิเศษ" (สูงกว่า 23 ม. / 8 ชั้น
หรือพื้นที่มากกว่า 10,000 ตร.ม.) ที่ต้องมีถนนกว้างอย่างน้อย 6 เมตรล้อมรอบอาคาร
เพื่อให้รถดับเพลิงเข้าถึงและกางอุปกรณ์ช่วยเหลือได้

## ⚠️ ข้อจำกัดของข้อมูล (สำคัญ)

- **พิกัดหมุดเป็นค่าประมาณ** กำหนดจากถนน/ซอย/สถานีรถไฟฟ้าที่ใกล้ที่สุด ไม่ได้มาจาก
  การรังวัดหรือ geocoding API จึงอาจคลาดเคลื่อนได้ในระดับ **ประมาณ 100–300 เมตร**
  ทุกแถวและทุกหมุดจึงมีปุ่มเปิด Google Maps เพื่อยืนยันตำแหน่งจริงของโครงการ
- **รายชื่อโครงการ** คัดลอกตามที่สภาผู้บริโภคเผยแพร่ แอปนี้เพียงนำมาแสดงบนแผนที่
  ไม่ได้ตรวจสอบหรือยืนยันข้อเท็จจริงเรื่องการปฏิบัติตามกฎหมายของแต่ละโครงการ
- **เขตและสถานีใกล้เคียง** เป็นข้อมูลประกอบเพื่อช่วยค้นหา ไม่ใช่ที่อยู่ตามทะเบียน
- **แหล่งอ้างอิง** รายชื่อชุดนี้ถอดมาจากโพสต์ของสภาผู้บริโภคที่ไม่ได้ให้ URL มาด้วย
  ลิงก์ใน `src/data/references.ts` จึงเป็นบทความของสภาผู้บริโภคที่กล่าวถึงการยื่นตรวจสอบ
  ชุดเดียวกัน (ค้นและตรวจ URL แล้ว) หากมี permalink ของโพสต์ต้นทาง ให้เพิ่มเป็นรายการแรก

หากต้องการความแม่นยำระดับพิกัดอาคารจริง แนะนำให้แทนค่า `lat`/`lng` ใน
`src/data/condos.ts` ด้วยผลจาก geocoding service (เช่น Google Geocoding API
หรือ Nominatim) หรือจากการปักหมุดด้วยมือบนแผนที่

## ฟีเจอร์

**เดสก์ท็อป — สองฝั่ง (breakpoint `md` ขึ้นไป)**

- ฝั่งซ้าย: ช่องค้นหา + ตัวกรองเขต + ตาราง MUI (เรียงลำดับได้ทุกคอลัมน์ + แบ่งหน้า 10/25/50)
- ฝั่งขวา: แผนที่แสดงเฉพาะโครงการที่ผ่านเงื่อนไขการค้นหา/กรอง

**มือถือ** — ใช้แท็บสลับระหว่าง "ตาราง" กับ "แผนที่"

**การเชื่อมโยงสองทาง**

- คลิกแถวในตาราง → หมุดที่ตรงกันถูกเน้น (เปลี่ยนเป็นสีน้ำเงินและใหญ่ขึ้น) และแผนที่เลื่อนไปหา
- คลิกปุ่มหมุด 📍 ในตาราง → เหมือนด้านบน และบนมือถือจะสลับไปแท็บแผนที่ให้อัตโนมัติ
- คลิกหมุดบนแผนที่ → เปิด popup พร้อมชื่อไทย/อังกฤษ เขต สถานีใกล้เคียง และปุ่ม Google Maps
  พร้อมทั้งเลื่อนตารางไปยังหน้าที่มีแถวนั้นและไฮไลต์ให้

**ลิงก์ Google Maps** ใช้ Google Maps search URL
(`https://www.google.com/maps/search/?api=1&query=<ชื่อโครงการ>`) จึงไม่ต้องใช้ API key

**สองภาษา (ไทย / English)** — สลับได้จากปุ่มมุมขวาบน

- ค่าเริ่มต้นดูจากภาษาของเบราว์เซอร์ (เบราว์เซอร์ภาษาอังกฤษ → English, อื่น ๆ → ไทย)
  และจำค่าที่เลือกไว้ใน `localStorage` พร้อมอัปเดต `<html lang>` และ title ของหน้า
- แปลทั้งชื่อโครงการ ชื่อเขต และชื่อสถานี — ไม่ใช่แค่ป้ายกำกับ UI
- **ค้นหาข้ามภาษาได้ทุกกรณี** พิมพ์ "ทองหล่อ" ตอนใช้ภาษาอังกฤษก็เจอ และพิมพ์ "Thong Lo"
  ตอนใช้ภาษาไทยก็เจอ
- การเรียงลำดับใช้ collation ของภาษาที่กำลังแสดง และ dropdown เขตเรียงตามตัวอักษรของภาษานั้น

**ส่วน "ทำไมเรื่องนี้สำคัญ"** อธิบายว่าทำไมพื้นที่รอบอาคารถึงเป็นเรื่องความปลอดภัย
(รถบันไดต้องมีที่ตั้งลำและกางขาค้ำยัน) ข้อกำหนดตามกฎหมาย และสิ่งที่สภาผู้บริโภคระบุว่าพบ
พร้อม **แหล่งอ้างอิง** ที่ลิงก์ไปยังบทความของสภาผู้บริโภคและตัวบทกฎกระทรวง — แก้ไขได้ที่
`src/data/references.ts` บนเดสก์ท็อปเป็นแผงพับที่จำกัดความสูงและเลื่อนในตัวเอง
บนมือถือเปิดเป็น dialog เต็มจอ

## เทคโนโลยี

- React 19 + TypeScript + Vite
- MUI (ตาราง เรียงลำดับ แบ่งหน้า ตัวกรอง แท็บ ธีม)
- Leaflet + react-leaflet พร้อม OpenStreetMap tiles (ไม่ต้องใช้ API key)
  หมุดเป็น `L.divIcon` ที่ใส่หมายเลขลำดับ จึงไม่ต้องโหลดไฟล์รูป marker

## การพัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build
npm run lint
```

## โครงสร้างไฟล์

```
src/
├── App.tsx                    # state กลาง (ค้นหา/กรอง/เรียง/แบ่งหน้า/การเลือก) + layout สองฝั่ง & แท็บ
├── components/
│   ├── FilterBar.tsx          # ช่องค้นหา + dropdown เขต
│   ├── CondoTable.tsx         # ตาราง MUI + เรียงลำดับ + แบ่งหน้า
│   ├── CondoMap.tsx           # แผนที่ Leaflet + หมุด + popup + การซิงก์มุมกล้อง
│   ├── WhyItMatters.tsx       # ส่วนอธิบาย + แหล่งอ้างอิง (พับบนเดสก์ท็อป / dialog บนมือถือ)
│   └── LanguageSwitch.tsx     # ปุ่มสลับ ไทย / EN
├── i18n/
│   ├── strings.ts             # ข้อความทั้งหมดทั้งสองภาษา (แก้คำที่นี่)
│   ├── context.ts             # context + hook `useI18n()`
│   └── LanguageProvider.tsx   # ตรวจภาษาเบราว์เซอร์ + จำค่าใน localStorage
├── data/
│   ├── condos.ts              # ข้อมูล 50 โครงการ (แก้พิกัดที่นี่)
│   ├── places.ts              # ชื่อเขต/สถานีภาษาอังกฤษ (lookup table)
│   └── references.ts          # รายการแหล่งอ้างอิง
├── utils/maps.ts              # Google Maps URL + ค้นหาข้ามภาษา + ป้ายกำกับตามภาษา
├── theme.ts                   # ธีม MUI
└── types.ts
```

การเพิ่มภาษาที่สาม: เพิ่มค่าใน `Lang`, เพิ่มบล็อกใน `strings`, และเพิ่ม lookup ใน
`data/places.ts` — TypeScript จะฟ้องทุกจุดที่ยังแปลไม่ครบ

หมายเหตุเชิงเทคนิค: บนมือถือ แผนที่ถูกซ่อนด้วย `display: none` ไม่ได้ unmount เพื่อไม่ให้
Leaflet ต้อง initialize ใหม่ทุกครั้งที่สลับแท็บ — แต่ container ขนาด 0×0 ทำให้ Leaflet
คำนวณพิกัดเป็น `NaN` และ throw ได้ ดังนั้นการสั่งเลื่อนมุมกล้องทุกครั้งจึงเช็ก
`map.getSize()` ก่อน และจะทำงานเมื่อแผนที่แสดงบนหน้าจอแล้วเท่านั้น (ดู `ViewportSync`)
